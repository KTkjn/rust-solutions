Rust基本情報
 借用チェッカーを使うことでメモリ安全性を保証できる
 ネイティブバイナリにコンパイルされるので速い
 C/C++やJavaと同じく静的型付き言語(⇄Python等の動的型付き言語)で､変数の型を変えられない
 オブジェクト指向でないのでクラスや継承は無い｡かわりにstructを使い､その振る舞いをtraitで定義する｡
 Rustはダンスパートナー
 ライブラリのことをクレートと呼ぶ｡かなり充実している｡
 Rustacean Rustを使っている人
 cargo.toml : プロジェクトの設定ファイル｡コンパイル後の名前など｡
 srcディレクトリ : ソースコード
 targetディレクトリ : 成果物
 main.rs : プログラムの開始地点

RustのShellCommand
 rustup : Rustのinstallやupdate,管理を簡単にできる
 rustup update
 rustup doc : document
 rustc --version : rustcコンパイラのバージョン確認
 cargo test
 cargo fmt : コードの自動整形｡著者はvimでファイルを保存するたびに実行されるようにしているらしい｡
 cargo clippy : コードの問題点を指摘してくれる
 rustc filename.rs : コンパイル
 cargo run : cargo内でのコンパイル(-qで静かに実行)
 cargo new directlyname
 cargo help コマンド名
 cargo test : testsフォルダだのコードを実行する
